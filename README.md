# Student Grade Management System

## Project Purpose
This is a Java console-based application designed for an educational institution transitioning away from traditional paper methods or rigid spreadsheets. The system lets educators store, track, and manage student information safely and digitally. It utilizes Core OOP principles such as Encapsulation and Data hiding.

## Features Included
* Add new student information securely (ID, Name, Marks).
* View all globally managed student profiles.
* Query and target specific student data via their Student ID.
* Compute the class performance average instantaneously.

## How To Run the Program
1. Ensure you have the **Java Development Kit (JDK)** installed on your operating system.
2. Clone this repository or copy the code files (`Main.java` and `Student.java`) into an empty directory.
3. Open your system Terminal / Command Prompt and switch to that folder path.
4. Compile the source code using:
```bash
   javac Main.java Student.java
